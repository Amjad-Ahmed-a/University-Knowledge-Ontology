# University Knowledge Ontology

## Project Overview
A collaborative university project focused on building a knowledge ontology for the College of Computing using Protégé and OWL. The project represents academic entities, relationships, and logical constraints to support knowledge representation and reasoning.

## Tools and Technologies
- Protégé
- OWL (Web Ontology Language)
- HermiT Reasoner
- SPARQL

## Project Components
- Classes and subclasses
- Object properties and data properties
- Domains and ranges
- Logical axioms and constraints
- Ontology reasoning
- SPARQL queries

## My Contribution
As part of the project team, I worked on:
- Defining and organizing data properties within the ontology.
- Working with logical axioms and constraints, including cardinality restrictions, disjoint classes, and equivalent classes.

## Project File
`Final_project.owl` — The ontology file, which can be opened using Protégé.
